# MoneyMakingMachine
Footage pre-selection: grades every part of your clips Good / Fair / Poor (contrast, exposure, focus, visual importance, shakiness)
and exports a colour-labelled timeline (XML) for Premiere Pro or DaVinci Resolve. Reads any format FFmpeg reads (MXF, MOV, MP4, MKV, AVI...).
Run from source: pip install -r requirements.txt && python app.py
